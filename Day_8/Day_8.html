What is Binary Number System?

Binary means two.A Number System which only two to 0 and 1 to represent any number is called "Binary Number System."

This Number System used in computer and Electronic Devices.

0 means no current passing through circuit.

1 means current passing through circuit.

Computer can understand only Binary Number System.It's can not understand a Human language. c, c++ , java, go ,rust all are the Higher language which used by Human to give a instruction to Computer which converted into binary number using compiler.
