What is Multidimensional Array?

An Array which has more then one Dimension it's called "Multidimensional Array."

1D Array : An Array which has only a 1 Dimension it's called "1D Array".it's store data into linear manner at continuous memory location.In 1D Array you can only Travel Linearly on data in one Direction only.

2D Array : An Array which has 2 Dimension it's called "2D Array".it's store data into Matrix or table or Row & Column formate at continuous memory location.In 2D Array you can Travel Row Wise or Column Wise on data in two Direction.

3D Array : An Array which has 3 Dimension it's called "3D Array".it's store data into Cube formate at continuous memory location.In 3D Array you can Travel Row Wise or Column Wise or Depth Wise on data in three Direction.

How 2D Array element store in memory?

2D array element are store at continuous memory location in memory.

it's use to method to store 2D array element

  1. Row Major
  2. Column Major

1 Row Major

Row Major : In row major each element of the 2d array are store in memory row wise at continuous memory location.

for example :

1 2 3 4 5 6 7 8 9
Memory location
100 104 108 112 116 120 124 128 132

2 Column Major

Column Major : In row major each element of the 2d array are store in memory Column wise at continuous memory location.

for example :

1 4 7 2 5 8 3 6 9
Memory location
100 104 108 112 116 120 124 128 132
