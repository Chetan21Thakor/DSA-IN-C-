Access Modifier

What is the Access Modifier?

Access Modifier are Keyword Which define a Which property and method of class is Accessible inside class only and Which property and method of the class can Accessible within class and outside a class. which property and method of the class is accessible within class and it's child class.

It's Provide Control Access on the Class Property and Method to it's Object. Where it's accessible where not.

There are Three Access Modifier.

  1. Private Access Modifier
    2. : A Property and Method which declare as Private it's only accessible within class only and it's friend Function and it's friend class.

  2. Public Access Modifier
    3. : A Property and Method which declare as Public it's accessible within class and anywhere in Program using it's Object.

  3. Protected Access Modifier
    4. : A Property and Method which declare as Protected it's only accessible within class only and it's derived class.

Constructor Method

What is Constructor Method and Why We need it?

Constructor Method is special type of the Method.

  • It's Has Same name as Class Name
  • It's Not has it's return type.
  • It's Automatically called when Object of the class Created.
  • Constructor Method is used to Initialize the Object of the class or for memory allocation of the object.
  • When we are not create Our Own Custom Constructor then Compiler create it's own Constructor to memory allocation of the object and initialize a object . Compiler always create non - parameterize Constructor.

There Are Three Type OF the Constructor.

  1. Non-Parameterized Constructor
    2. : A Constructor which is Automatically Created by a Compiler it's non-parameterized Constructor.A Constructor not have any parameter it's called "non- Parameterized Constructor".

  2. Parameterized Constructor
    3. :A Constructor which is Manually Created by a Programer to initialize Object with some value that time parameterized Constructor Created by a Programer with some parameter it's called "Parameterized Constructor".

  3. Copy Constructor
    4. :When we want to copy one object properties into another object then copy Constructor is used. It's Just copy the one object value of the properties into another object.
    IF we not create own copy Constructor for class then Compiler Automatically Create copy Constructor.

Shallow Copy and Deep Copy of the Object

What is Shallow Copy and Deep Copy of the Object?

When we trying to copy one object into another object then if Custom copy Constructor Created by Programer then Compiler call that copy Constructor if we not create any copy Constructor then Compiler Automatically create copy Constructor and call that copy Constructor.

Default Copy Constructor create a Shallow copy of the Original Object or Source Object into destination object.

Shallow Copy Means If the Class any property has dynamically memory allocation that time if we are trying to copy one source object into another destination object them destination object easily copy that static property without any issue but when it's try to copy dynamically allocated property then it's just copy the same memory address which store inside source object property means both are pointing same memory address in heap. so that if we make changes in one object dynamically allocated property then it's changes reflect into another object It's Called "Shallow copy of the Object."

Default Copy Constructor always create a Shallow copy of the Object so that we have to create our own Copy Constructor which can Create a Deep Copy of the Object.

Deep Copy of the Object to create a Deep copy of the Object we create our own copy Constructor which can create deep copy of the Object.

Deep Copy Means If any property of the class has dynamically memory allocation then source object and destination object which copy the properties of the source object both are pointe a different memory location in heap but store same value. 

          
            #include <iostream>
            using namespace std;

            class Car
            {
            public:
                string name;
                string color;
                int *milage;

                Car(string name, string color)
                {
                    this->name = name;
                    this->color = color;
                    this->milage = new int;
                    *milage = 12;
                }

                //Shallow Copy
                Car(Car &source)
                {
                    this->name = source.name;
                    this->color = source.color;
                    (this->milage) = (source.milage);
                } 

                //Deep Copy
                Car(Car &source)
                {
                    this->name = source.name;
                    this->color = source.color;
                    this->milage = new int;
                    *(this->milage) = *(source.milage);
                }
            };

            int main()
            {
                Car c1("BMW", "black");
                Car c2(c1);

                cout << c2.name << endl;
                cout << c2.color << endl;
                cout << *(c2.milage) << endl;

                *c2.milage = 10;
                cout << *(c2.milage) << " != ";
                cout << *(c1.milage) << endl;

                return 0;
            }

Destructor Method

What is Destructor Method? and way we Need a Destructor Method?

Destructor Method is special type of Method of the class.

  • Destructor method has same name as class name but it's name start with tilt Symbol.
  • Destructor method has not it's return type.
  • Destructor method has it's Automatically called when main() Function scope is end or when the main() Function execution complete successfully or exact before a return statement of the main() Function.
  • Constructor is for memory allocation and initialize object and Destructor is for exact opposite task .Destructor is for Memory deallocation and destroy a object free a memory.
  • If We are not create Destructor then Compiler create it's own Destructor for destroy a object.

Most of the time we are not create Destructor but when the any property of the class has dynamical memory allocation that time to free that memory or solve memory leak problem we create Custom Destructor.

Inheritance In Class

What is Inheritance and Why we need Inheritance?

Inheritance is concept in which we are inherit properties or methods of the one class to another class.

A class which inherit or giving access of it's properties and methods it's class called "Parent Class" or "Super Class" or "Base Class".

A class which inheriting or taking access of another class properties and methods it's class called "Child Class" or "Sub Class" or "Derived Class".

Types Of The Inheritance

  1. Single Inheritance
    2. :In Single Inheritance only one parent class and only one child.
  2. multi level Inheritance
    3. :In multi level Inheritance only one parent class and only one child but level by level it's inherit one class property to another class in multi level it's called "multi level Inheritance".
  3. multiple Inheritance
    4. :A Child class inheriting properties and methods of the multiple parent classes it's called "multiple Inheritance".One child class and more then one parent or base class.
  4. Hybrid or Hairarchical Inheritance
    5. : it's Combination of the above all type of the Inheritance it's can contain Single Inheritance or multi level Inheritance or multiple Inheritance in any order.

Single Inheritance Example

            
              #include <iostream>
              using namespace std;

              class ParentClass
              {

              public:
                  string name;
                  int age;

                  ParentClass(){

                  }

                  ParentClass(string name, int age)
                  {
                      this->name = name;
                      this->age = age;
                  }

                  void showInfo()
                  {
                      cout << "Name is :" << this->name << endl;
                      cout << "age is :" << this->age << endl;
                  }
              };

              class ChildClass : public ParentClass
              {

              public:
                  ChildClass(string name, int age)
                  {
                      this->name = name;
                      this->age = age;
                  }
              };

              int main()
              {
                  ParentClass p1("Chetan", 28);
                  ChildClass c1("Shivashi", 1);

                  c1.showInfo();
                  p1.showInfo();
                  return 0;
              }
