When you are want to give dynamic size to array at run time then you have to use a New Operator.

New Operator assign a new memory to any data structure. It's used to assign new memory to any variable or any data structure.

Dynamic Memory Allocation

            
              int *arr=new int[n];

Dynamic Memory Allocation done at compile time Dynamically.
Dynamically means changeable or variable type. it's size can be change at run time of the program.

Dynamic Memory Allocation done in Heap Memory.
To allocate a heap memory to any variable or any data structure you have to use a new Operator.

Dynamic Memory allocated memory not free automatically you have to explicitly delete or remove using delete Operator or keyword. 

            
              delete []arr;

After the c++ entire file execution was completed stack and heap both memory automatically delete from RAM.

What is Memory Leak ?

A Programer allocate a heap memory to any variable or any data structure and forgot to delete then heap memory remain as it is in memory any other variable or data structure can't can use it's just because of it's already filled by another data.It's called "Memory Leak."
