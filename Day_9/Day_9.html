Passing Argument to Function

There are to Way to pass a Arguments to a Function?

  1. Pass By Value
  2. Pass By Reference
    1. Using a Pointer
    2. Using a Reference Variable

Pass By value

When we passing a Argument to a function it's by default done by a pass by value.

What Exactly Happen in Pass By Value?

When we are Passing Argument to a Function then function store copy of the argument in parameter and all the operation done on the parameter it's don't reflect on the actual argument.

Pass By Reference

When we passing a Argument to a function it's by default done by a pass by value.

What Exactly Happen in Pass By reference?

When we are Passing Argument by Reference to a Function then function store memory address of the passing argument and all the operation done on the actual argument just because of it's both are pointing same memory location. it's reflect on the actual argument.

There are two way to pass Argument to function by Reference

  1. Using a Pointer
  2. Using a Reference Variable

What is Reference Variable?

A Reference Variable is the alternative name (alias) of the already exiting variable.

Means giving another name to same variable which refer a same memory address.
