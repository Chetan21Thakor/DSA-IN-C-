Character Data Type

Character data type is primitive data type.

It's take 1 byte of space in memory.

It's can store alphabet 'a' - 'z' , 'A' - 'Z' ,digit '0' - '9', escape sequence Character '\t','\n', special Character '*','$','#','@' ect.. 

                    
                        #include <iostream>
                        #include <cstring>
                        using namespace std;

                        int main(){
                            //which type of character value character data type can store.
                            char ch='a';
                            char ch1='!';
                            char ch2='5';
                            char ch3='A';
                            char ch4='\n';
                        }

internally all the Character are store in memory in from of the Binary number when it's convert into decimal number then it's represent as integer value.

In Integer Each and Every Character are represent as ASCI code. Each and Every Character it's own and unique ASCI code.

ASCII Stand for : American Stander Code Interchangeable Information. It's represent the 128 Character with is unique code.

ASCI Code of 'a' is 97.

ASCI Code of 'A' is 65.

You can easily check it's ASCI Code using explicity typecasting.

Converting Character data into integer Data. 

                
                    int ascii_code_a=int('a'); // 97
                    int ascii_code_A=int('A'); //65
How to find out the index or position of the any Character in English lower case and uppercase alphabet?

                    //position of any uppercase letter in uppercase alphabet.
                    int pos =ch-'A';

What is a C++ String?

C++ String is Object of the pre-defined class String in STL.STL is C++ Stander Template Library which contain a definition of the String , vector, linked list,stack ,queue different-different data structure logic and Class of that data structure Library.

STL Contain a useful header file of the string,vector,stack ,queue.

  • C++ String has different-different useful member function.

  • C++ String are dynamic size (Their size can be change at run time).

  • C++ String Support Operator lik ==,<,>,+ ect.

  • C++ String Store at contiguous memory location.

  • C++ String take 32 byte of space in memory.
