Polymorphism

What is Polymorphism Why We Need Polymorphism?

A Polymorphism is ability of the Object to take a more then one form or behave in different way based on it's context pass.

In simple Meaning of the Polymorphism is same name but different task based on arguments or parameter. form.
Poly Means : Multiple. Mor Means : Form.

There are Two Type of the Polymorphism

  1. Compile Time Polymorphism
  2. Run Time Polymorphism

1. Compile Time Polymorphism

IN Compile Time Polymorphism Compiler Know automatically at compile time which function or which Operator it's have to call based on it's pass arguments.

Example of Compile Time Polymorphism

  1. Function OverLoading
    2. :A Function with a same name but different - different form and it'a automatically called based on it's passed arguments it's called "Function OverLoading".

  2. Operator OverLoading
    3. :A same Operator but with different - different definition or different form and behave in different manner based on it's Operand passed it's called "Operator OverLoading".

Function OverLoading in Code

            
                #include <iostream>
                using namespace std;

                class Addition {

                public:
                    //Function OverLoading
                    int add(int a,int b){
                        return a+b;
                    }

                    int add(int a,int b,int c){
                        return a+b+c;
                    }

                    int add(int a,int b,int c,int d){
                        return a+b+c+d;
                    }

                    int add(int a,int b,int c , int d , int e){
                        return a+b+c+d+e;
                    }

                    double add(int a,double b){
                        return a+b;
                    }

                    float add(float a,double b,int c){
                        return a+b+c;
                    }

                    
                };

                int main()
                {
                    Addition a;

                    cout << "Sum is : " << a.add(1,2)<< endl;
                    cout << "Sum is : " << a.add(1,2,3)<< endl;
                    cout << "Sum is : " << a.add(1,2,3,4)<< endl;
                    cout << "Sum is : " << a.add(1,2,3,4,5)<< endl;
                    cout << "Sum is : " << a.add(1,2.9)<< endl;
                    cout << "Sum is : " << a.add(1.5,2.9,10)<< endl;
                    return 0;
                }

Operator OverLoading in code

            
                #include <iostream>
                using namespace std;

                class ComplexNumber
                {
                    int real;
                    int img;

                public:
                    ComplexNumber()
                    {
                    }
                    ComplexNumber(int real, int img)
                    {
                        this->real = real;
                        this->img = img;
                    }

                    ComplexNumber operator+(ComplexNumber &c2)
                    {
                        ComplexNumber c3;
                        c3.real = this->real + c2.real;
                        c3.img = this->img + c2.img;

                        return c3;
                    }

                    ComplexNumber operator-(ComplexNumber &c2)
                    {
                        ComplexNumber c3;
                        c3.real = this->real - c2.real;
                        c3.img = this->img - c2.img;

                        return c3;
                    }

                    void showComplexNum()
                    {
                        cout << "Complex Number is : " << this->real << " + " << this->img << "i ." << endl;
                    }
                };

                int main()
                {

                    ComplexNumber c1(2, 7);
                    c1.showComplexNum();
                    ComplexNumber c2(1, 4);
                    c2.showComplexNum();
                    ComplexNumber c3 = c1 - c2;
                    
                    c3.showComplexNum();
                    return 0;
                }

Run Time Polymorphism

A Compiler Don't at compile time which Function it's have to call it's decide a which function it's have to call at time of execution it's called "Run Time Polymorphism".

Function Overriding is Example of the Run Time Polymorphism.

What is Function Overriding ?

A One class inherit a properties and method of the another class that time a function which already define inside a parent class but it's redefine inside a child class which over power parent class function means if child class call that function that time a function which is redefine inside a child it'a called it's called "Function Overriding".

It's Done in Inheritance Only.

Compiler Don't at compile time which function it's have to call. A function which id define inside a parent class or A function which is redefine inside a child class.

Then it's decide at execution time of the program to it's have to call . A function which is define inside a child class.

It's Done using two way

  1. Normal redefining Function in child class.
  2. Virtual function redefining in child class.

Abstraction In Class

What is Abstraction and Why we Need it?

A Abstraction is Hiding all the unnecessary Details and just showing important data it's called "Abstraction"

in class we are declare a some properties as Private to Hiding data and some properties and method makes to show important data it's is example of the "Abstraction".

Abstraction Mean Unclear definition of the thing or object which can't be define.

What is Abstraction class and Abstraction Function?

Abstraction function : A virtual Function which logic define as 0 (zero) or a virtual function which unimplemented it's called "Pure Virtual Function" or "Abstraction function".

Abstraction function mean :" A function which definition is Unclear to which constantly changed."
Abstraction function are always define inside child class. Abstraction Class : A class which contain one or more then one Pure Virtual Function it's called "Abstraction class".

Abstraction class mean :" A class which definition is Unclear."
we can not create a object of the Abstraction Class.
Abstraction Class is only used to Inheritance.
Abstraction Class define how it's child looks how there behave.
