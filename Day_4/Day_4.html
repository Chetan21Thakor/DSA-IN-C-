3.Ternary Operator

What is ternary Operator? How it's work?

Combination of  '?' & ':' it's called "Ternary Operator".

it' called Ternary Operator just because of the it's need three Operands to done it's Operation or task.

Syntax of Ternary Operator

int age =17;

string result=(age >=18) ? "you can vote" : "you can not vote" ;

cout << result;

Ternary Operator Also first check a condition if the condition is true then it's executed a code or return value which immediately come after a "question mark ?" otherwise it's executed a code or return a value which immediately come after a " colon :".

Ternary Operator is short hand of the if else statement. it's used when if else statement is very small or simple to handle.
