Chapter 11: Sorting Algorithm

What is Sorting ?

Sorting is process in which we are arranging a element in Ascending or Descending Order.
Ascending Order Means : "arranging a element from small to bigger."
Descending Order Means : "arranging a element from bigger to smaller."

What is Sorting Algorithm?

Algorithm which is used to sort element into specific order it's called Sorting Algorithm.

List of Basic Sorting Algorithm

  1. Bubble Sort
  2. Selection Sort
  3. Insertion Sort
  4. Count Sort
  5. Marge Sort

All the sorting Algorithm work on basic comparison logic to arrange or sort element into Ascending order or Descending order.
